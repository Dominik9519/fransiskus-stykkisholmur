# Fransiskus Stykkishólmur

English parish website prepared as a standard Next.js project for deployment on Vercel.

## Run locally

1. Install Node.js 20 or newer.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Deploy on Vercel

1. Create a new GitHub repository and upload the contents of this folder.
2. In Vercel, select **Add New → Project**.
3. Import the GitHub repository.
4. Keep **Framework Preset: Next.js** and the default build settings.
5. Select **Deploy**.

All images required by the current page are included in the `public` folder.
